# Artificial Intelligence Algorithms

Academic Python implementations exploring search and optimization. The repository URL retains its original spelling so existing course and external links continue to work.

| File | Topic |
| --- | --- |
| `A_Star_Search.py` | Heuristic graph search with path reconstruction |
| `Simulated_Anneling.py` | Simulated annealing exercise |

## Run

Use Python 3. Inspect the example inputs in each script before running.

```bash
python A_Star_Search.py
python Simulated_Anneling.py
```

The examples use Python's standard library. They are educational implementations, not evaluated research models or production optimization systems. Results depend on the input and, for stochastic methods, the random choices.
